# [DRAFT] 一緒に読み込んだ図の一括書き出しを「一括 ▾」1 つの選択にする

- ステータス: ドラフト(未採番。承認後 /adr で正式登録)
- 日付: 2026-09-26
- 起点: BLK-primary-20260926-1205(primary 手順 9: 12 枚を SVG と Excel で一括に書き出せない)

## コンテキスト
書き出し(SVG / PNG / 透過PNG / Excel / Mermaid)は表示中の図だけを見ていた。「.sb 読込」で 12 枚 + 共通部を一緒に選んでも、
1 枚ずつ開いて押すしかなかった。owner の統合案は「各書き出しボタンの横に ▾」。

## 選択肢
1. 各書き出しボタンの横に ▾(5 個)。▾ →「読み込んだ全部の図(N 枚)」
2. 書き出しの並びの後ろに「一括 ▾」を 1 つ。開くと見出し「読み込んだ全部の図(N 枚)」と形式(SVG / PNG / 透過PNG / Excel / Mermaid)
3. 拡張・CLI に一括書き出しを足す

## 決定
案 2。どちらも 1 形式 2 クリックで同じだが、案 1 は 1600px 幅でツールバーの幅が足りず、ほかのボタンの名前が 2 行に折れた(実測)。
語彙の原則(入口の名前は何をするかで付け、記号だけにしない)にも案 2 の「一括 ▾」が合う。出るのは一緒に読み込んだ図が 2 枚以上のときだけで、
1 枚の書き出しは今までどおり 1 クリック。案 3 は BLK の範囲外(入口は HTML 版の 1 か所)。
include の探し方は表示中の図と同じ規則を core(`loadedReader`)に 1 つだけ持ち、表示と一括書き出しの両方が使う。
zip の中の名前は読み込んだパスの拡張子を差し替えたもの、知らせは図の名前を頭に付けて 1 つの一覧に並べる(`bulkDrops`)。

## 影響
- PNGをコピーは一括の対象外(クリップボードに複数枚は置けない)
- 共通部(include されるだけの図)も 1 枚として zip に入る
