# ECN-003: ラベル入力時のフォーカス喪失

- **ステータス**: 解決済
- **対象コミット**: `a2c816b`
- **影響ファイル**: `stableblock.html`, `vscode-stableblock/src/extension.js`

## コンテキスト

プロパティパネルのラベル入力欄で文字を入力するたびにフォーカスが外れ、2回目のBackspaceキーでブロックが削除される不具合が発生した。

## 問題の詳細

`setLabel()`（VSCode版: `sLb()`）がラベル変更時に `refresh()`/`go()` を呼び出しており、これがプロパティパネル全体のHTMLを再構築していた。HTMLの再構築によりinput要素が破棄・再生成され、フォーカスとカーソル位置が失われた。

フォーカス喪失後のBackspaceはブロック削除操作として解釈されるため、ユーザーがラベル編集中にBackspaceを押すとブロックが消えるという深刻な副次的問題を引き起こした。

## 対策

ラベル編集中は `refresh()`/`go()` の呼び出しをスキップし、必要最小限の処理のみ実行するようにした。

```
変更前: setLabel() → refresh() → renderProps() でパネル全体を再構築
変更後: setLabel() → parseDSL() + syncEditor() + renderSVG() + renderErrors() + renderStatus()
```

`renderProps()`（プロパティパネル描画）を除外することで、input要素が破棄されずフォーカスが維持される。

## 結果

- ラベル入力中のフォーカスとカーソル位置が保持される
- Backspaceによる意図しないブロック削除が解消
- SVG描画やDSL同期はリアルタイムに反映される
