# [DRAFT] 注釈(note)を既定で表示し、通常モードで block と同じに選択・移動・追加できるようにする

- ステータス: ドラフト(未採番。承認後 /adr で正式登録)
- 日付: 2026-09-25
- 起点: BLK-owner-20260925-1921-3(注釈が既定で見えず、足すのに 4 手順かかる)
- 関係 ECN: ECN-008(モード別ツール表示)、ECN-010(注釈ボタンの初期状態を非表示に)、ECN-020(注釈レイヤーの 2 モード)

## コンテキスト
ECN-020 は note を「通常モードでは表示のみ、✎ 編集モードでだけ操作(block/group はロック)」に分け、ECN-010 は初期状態を非表示にした。
その結果、Import した図の note が描かれず(porter 手順 3 が満たせない)、note を 1 つ足すのに「◇ 注釈」→「✎ 編集」→ 選択解除 →
「+ 注釈追加」の 4 手順が要り、Ctrl+A → Delete で note だけが残った。draw.io / Visio は注釈もテキスト図形として同じパレットから置け、既定で全部見える。

## 選択肢
1. 現状のモード分離を保ち、Import 時だけ表示をオンにする
2. note を既定で表示し、通常モードで block/group と同じに選択・移動・リサイズ・削除できるようにする。「+ 注釈追加」を通常のツール欄に置く。
   ✎ 編集モードは「note だけを触る(block/group をロック)」補助として残す
3. 2 に加えて ✎ 編集モードを削除する

## 決定
案 2。表示の既定と追加の手数を block/group に揃えるのが目的で、編集モードを消すと密な図で note だけを動かしたい利用者の手段が無くなる。
◇ 注釈は表示/非表示の切替として残り、非表示にすると note は選択から外れ、書き出し(SVG/PNG)にも含まれない(ECN-020 の規則のまま)。
HTML 版と VSCode 拡張の両方に同じ変更を入れる(描画・操作の UI 層は各実装にあるため core/ には寄せない)。

## 影響
- 既定で SVG/PNG 書き出しに note が含まれる(以前は ◇ 注釈を押さないと含まれなかった)
- 通常モードの Ctrl+A は note も選ぶ(表示中のとき)。✎ 編集モード中の Ctrl+A は従来どおり note だけ
- 通常モードで note は不透明(以前は 0.7 の半透明で「触れない」を表していた)
