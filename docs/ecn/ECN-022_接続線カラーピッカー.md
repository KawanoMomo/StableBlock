# ECN-022: 接続線カラーピッカー

- **ステータス**: 適用済
- **種別**: 機能追加
- **対象コミット**: `d2c36b1`
- **影響ファイル**: `stableblock.html`, `vscode-stableblock/src/extension.js`

## コンテキスト

接続線の色が全てデフォルト色で統一されており、接続の種類や重要度を色で区別できなかった。

## 対策

2ブロック選択時のプロパティパネルに12色のカラーピッカーを追加。

### 新規接続時

接続がない状態で色を選んで接続すると、DSLに `color=` 属性付きで接続が作成される。

```
connect block_a -> block_b color=#EF4444
```

### 既存接続の色変更

接続済みの場合、カラードットをクリックして色を変更。`setConnColor()` がDSL内の `color=` 属性を更新（既存の場合は置換、ない場合は追加）。

## 効果

- データフロー、制御フロー、エラーパスなどを色で視覚的に分類可能
- DSL属性として永続化されるため、エクスポート時も反映
