# ECN-018: プロパティパネル拡張と矢印キー移動

- **ステータス**: 適用済
- **種別**: 機能追加
- **対象コミット**: `f91587e`
- **影響ファイル**: `stableblock.html`, `vscode-stableblock/src/extension.js`

## コンテキスト

2ブロック選択時の接続操作にDSL手動編集が必要で非効率だった。またブロックの位置調整がドラッグのみで、1グリッド単位の微調整が困難だった。

## 対策

### 1. 2ブロック選択時の接続管理パネル

2つのブロックを選択した状態でプロパティパネルに接続管理UIを表示。

| 機能 | 関数 | 説明 |
|------|------|------|
| 接続作成 | `connectTwo()` | 2ブロック間に新規接続を追加 |
| 接続削除 | `removeConn()` | 既存接続を削除 |
| 方向反転 | `flipConn()` | 接続の向きを逆転 |
| 双方向化 | `toggleBidir()` | `->` と `-->` を切替 |

### 2. グループ内ブロック追加

グループ選択時のプロパティパネルに「ブロック追加」ボタンを表示。`addBlockInGroup()` がグループ範囲内の空き位置を計算し、行送りと必要に応じたグループ高さの自動拡張を行う。

### 3. 矢印キーによるグリッド移動

Arrow Up/Down/Left/Right で選択中のブロック/グループを1グリッド単位で移動。

- 単一選択: `nudge()` で個別移動
- 複数選択: `batchNudge()` で一括移動

## 効果

- 接続の作成・削除・反転がDSL編集なしで可能
- グループ内へのブロック追加がワンクリック
- ピクセル精度の位置調整が矢印キーで可能
