# ECN-020: 注釈レイヤー

- **ステータス**: 適用済
- **種別**: 機能追加
- **対象コミット**: `9f4aa41`, `816ed6c`, `e816f90`
- **影響ファイル**: `stableblock.html`, `vscode-stableblock/src/extension.js`

## コンテキスト

ブロック図に対して補足説明や注意書きを配置する手段がなく、別途ドキュメントで補足する必要があった。

## 対策

ブロック/グループとは独立した「注釈レイヤー」を新設。ブロック図の上にオーバーレイ表示される。

### DSL構文

既存のblock/group構文と同じパターンで `note` キーワードを使用。

```
note warning "ここは要注意" at 10,5 size 8x3 color=#FEF3C7
```

### 2つのモード

| モード | トグル | 操作可能な要素 |
|--------|--------|---------------|
| 通常モード | ◇ 注釈ボタン / Nキー | ブロック・グループ（ノートは表示のみ） |
| 編集モード | ✎ 編集ボタン | ノート（ブロック・グループはロック） |

### 編集モード時のディミング

通常のブロック・グループ・接続線を15% opacityで透過表示し、ノートのみが操作対象であることを視覚的に明示。カーソルも `default` に変更してロック状態を伝達。

### ノート接続

ノートとブロック間の接続は常に破線 (`stroke-dasharray="6,3"`) で描画し、通常の接続線と視覚的に区別。

### その他の統合

- `Ctrl+A`: モードに応じて選択対象を切替（通常→ブロック/グループ、編集→ノート）
- `fixNames`: ノートのID補正にも対応
- エクスポート: 表示/非表示状態を尊重（非表示ノートはSVG/PNGに含まない）
- プロパティパネル: ノート固有のカラーパレット（NOTE_COLORS）とテキスト色選択

## 効果

- 図内に直接注釈を配置でき、自己完結したドキュメント性の高い図が作成可能
- モード分離により通常操作時にノートが干渉しない
