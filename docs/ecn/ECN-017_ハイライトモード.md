# ECN-017: ハイライトモード

- **ステータス**: 適用済
- **種別**: 機能追加
- **対象コミット**: `2b9ede0`
- **影響ファイル**: `stableblock.html`, `vscode-stableblock/src/extension.js`

## コンテキスト

大規模な図で特定のブロック群の接続関係を把握したい場合、視覚的なノイズ（接続のないブロック）が妨げになっていた。

## 対策

HLボタンまたはHキーでトグルする「ハイライトモード」を追加。接続のないブロック・グループ・接続線を15%のopacityで透過表示し、接続のあるブロックのみを強調する。

### 判定ロジック

```
getConnectedIds()    → 接続に参加する全ブロックIDのSetを取得
getHighlightedGroups() → 接続ブロックを含むグループIDのSetを取得
isHighlightedConn()  → 両端が接続ブロックに含まれるかを判定
```

### SVGレンダリングへの適用

- 非接続ブロック/グループ: `opacity: 0.15`
- 非接続間の接続線: `opacity: 0.15`
- 接続ブロック: `opacity: 1.0`（通常表示）

### エクスポート対応

SVG/PNGエクスポート時もハイライト状態が反映される（ディミングされたブロックは薄く出力）。

## 効果

- 接続関係のある部分が視覚的に浮き上がり、依存関係の把握が容易
- エクスポート画像にもフィルタが反映され、ドキュメント用途に活用可能
