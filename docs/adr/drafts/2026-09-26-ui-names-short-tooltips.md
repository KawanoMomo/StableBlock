# [DRAFT] 画面に出す名前は短く、説明はツールチップで補う

- ステータス: ドラフト(未採番。承認後 /adr で正式登録)
- 日付: 2026-09-26
- 起点: BLK-human-20260926-2045-2(v1.0 所感「入口の名前・説明がやりすぎで UI としてチープに感じる。カーソルを合わせたら補足するくらいでよい」)
- 改める判断: `2026-09-26-ui-terms-core.md` の「名前は何をするか」(「◎ 未接続を薄く」「⌇ 線の形: 曲線」「+ グループ内にブロック追加」)

## コンテキスト
BLK-owner-20260925-1921-7 で略語・絵文字だけの名前をやめ、入口の名前に「何をするか」を書いた。あわせてプロパティ欄に
操作の説明文(複製の手順、結び方、ID の決まり、取り込むパスの書き方、キャンバスの自動拡張の効き方、ショートカット一覧)を常に出していた。
人間の所感は、名前も説明も画面に出しすぎで安っぽく見える、というもの。draw.io・VSCode・Figma も、入口は短い名前かアイコンで、説明はツールチップに置く。

## 選択肢
1. 名前は今のまま、説明文だけを減らす
2. 名前を短く(8 文字以内)し、何をするか・どう効くかはツールチップ(title)へ移す。常に出す説明文もツールチップか畳んだ欄へ移す
3. 名前をアイコンだけにする

## 決定
案 2。語彙表(`core/terms`)の ja の名前は 8 文字以内(unit で守る)、ツールチップは名前より詳しく何をするかを言う。
- ツールバー: 「⌇ 曲線」(押すと 直線 / 直角)、「◎ 未接続」、「◇ 注釈」、検索欄の見出し「🔍 検索」、PNG の ▾ は「透過PNG」「コピー」
- プロパティ欄: グループ欄の追加は「+ 中にブロック」(ツール欄の「+ ブロック追加」と別の名前のまま)、共通部は「取り込む」「すべてに取り込む」
- 常に出していた説明文はツールチップへ: 複製の手順(種類の見出し)、2 つ・3 つ以上選んだときの結び方(結ぶボタン)、続けてラベルを打つ案内(ラベル欄)、
  ID の決まり(ID 欄)、改行の書き方(ラベル欄)、本文に書くパス(パス欄)、キャンバスの自動拡張の効き方(「はみ出したら自動で広げる」)
- 結び方とショートカットの一覧は、ツール欄の下の畳んだ「操作とキー」に入れる(押せば開く)
- 状態の知らせ(ほかの図でも使う ID、仮の ID の警告、取り込んだ結果、include 先の要素の案内)はその時だけ出すので画面に残す
- 拡張(en)は短い語のままなので変えない

## 影響
- 名前で押す E2E(junior-02・04・06、porter-06、primary-01・02)は新しい名前を追い、説明文の有無はツールチップ(title 属性)で確かめる
- 案 3(アイコンだけ)は採らない。絵文字だけの名前は何の入口か分からない(BLK-owner-20260925-1921-7 の指摘は残す)
