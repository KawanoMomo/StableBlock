# ADR ドラフト: 表示中の図 1 枚の書き出し(SVG / PNG / 透過PNG / PNGをコピー)は画面の見た目(薄め・注釈の表示)のまま描く

- 状態: ドラフト(採番は人間)
- 関連: BLK-human-20261012-1432-1(人間の所感: クリップボードのコピーが画面の見た目を保持しなくなった)、
  BLK-human-20261012-1432-2(「◎ 未接続」のまま保存した PNG が画面どおりに薄まらない)、
  `2026-09-26-render-core-export.md`(書き出しは画面の状態を持ち込まない)、ECN-017(ハイライトモード。当初は書き出しにも薄めが入った)

## コンテキスト
ECN-017 の時点では SVG / PNG / コピーは画面の SVG を直列化していたので、「◎ 未接続」の薄めが画像にも入り、資料に
「依存の無い部品を薄くした図」を貼れた。render-core-export(BLK-owner-20260926-0609-1)で書き出しを本文だけの絵に揃えたとき、
選択の枠・ハンドル・グリッド・倍率と一緒に薄めも落ちたため、人間から見ると「コピーも保存も見た目どおりでなくなった」退行になった。

## 検討した案
1. 画面の SVG を直列化する方式に戻す — 選択の枠・ハンドル・グリッド・倍率がまた入る(render-core-export で直した不具合の再発)
2. 全部の書き出し(1 枚・一括)に薄めを持ち込む — 一括は画面に出ていない図も書き出すので、表示中の図の状態をほかの図に当てる意味が無い
3. 薄めを持ち込むのは「PNGをコピー」だけにし、保存は本文だけ — 同じ画面からコピーと保存で絵が違い、人間が保存側の不一致を指摘した(-2)
4. **core/render に `viewExportSvg(parsed, view, …)` を足し、薄め(highlight・search)と注釈の表示切替だけを view から受け取る。
   選択・ハンドル・スナップガイド・グリッド・見比べの印・倍率は持ち込まない。表示中の図 1 枚の書き出し(SVG / PNG / 透過PNG / PNGをコピー)がこれを使う** — 採用

## 決定
- `viewExportSvg` は薄めも注釈を隠すことも無い画面では `exportSvg` とバイト一致(unit で確かめる)。大きさは exportSvg と同じ(@canvas、PNG は × 2)
- 表示中の図 1 枚の書き出し(HTML 版・VSCode 拡張)は viewExportSvg。HTML 版は書き出し後のステータスバーに、持ち込んだ見た目(未接続を薄く・検索の薄め・注釈を隠す)を出す
- 「一括 ▾」・Excel / Mermaid / JSON Canvas は本文だけ(exportSvg・各形式の変換)

## 影響
- 「◎ 未接続」を付けたまま書き出すと、画像でも未接続の要素が薄い(意図した見た目)。本文だけの絵が欲しければ「◎ 未接続」・検索を外して書き出す
- 「同じ本文はどの画面でも同じ絵」は薄めも注釈を隠すことも無いときに限られる(書き出しのボタンのツールチップに「画面の薄め・注釈の表示のまま」と書いた)
