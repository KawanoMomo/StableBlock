# ECN-027: バージョン一元管理

- **ステータス**: 適用済
- **種別**: 開発プロセス改善
- **対象コミット**: `19aa483`
- **影響ファイル**: `VERSION`, `bump-version.sh`, `README.md`, `vscode-stableblock/README.md`

## コンテキスト

バージョン番号が複数ファイルに分散しており、手動で更新するとバージョン不整合が発生する可能性があった。

## 対策

### VERSIONファイル

`VERSION` ファイルを唯一のバージョン情報源（Single Source of Truth）として新設。

### bump-version.sh

全ファイルのバージョン参照を一括更新するスクリプト。

更新対象:
1. `VERSION` ファイル本体
2. `vscode-stableblock/package.json` の `"version"` フィールド
3. `stableblock.html` のバッジ表示とデフォルトDSLコメント
4. `README.md` と `vscode-stableblock/README.md` のvsixファイル名

## 後続

ECN-014にてHTMLバッジの正規表現パターン不一致が発見・修正された。

## 効果

- バージョン更新が1コマンドで完結
- ファイル間のバージョン不整合を防止
