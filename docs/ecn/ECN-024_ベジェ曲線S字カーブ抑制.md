# ECN-024: ベジェ曲線のS字カーブ抑制

- **ステータス**: 適用済
- **種別**: 改善
- **対象コミット**: `91efcce`
- **影響ファイル**: `stableblock.html`, `vscode-stableblock/src/extension.js`

## コンテキスト

ECN-005で導入した3次ベジェ曲線の制御点距離が `max(30, dist*0.4)` で計算されるが、隣接する近いブロック間（例: 40px間隔）で制御点距離30pxが間隔の大部分を占め、制御点同士が交差してS字カーブが発生していた。

## 対策

制御点距離 `cpd` にブロック間の方向ギャップに基づくクランプを追加。

```javascript
// ベースライン計算
cpd = Math.max(30, dist * 0.4);

// 方向ギャップによるクランプ
const gap = isHorizontal ? Math.abs(dx) : Math.abs(dy);
cpd = Math.min(cpd, gap * 0.45);
```

### 動作例

| ブロック間距離 | ベースcpd | ギャップの45% | 適用cpd | 結果 |
|---------------|----------|-------------|---------|------|
| 40px | 30 | 18 | 18 | ほぼ直線 |
| 80px | 32 | 36 | 32 | 緩い曲線 |
| 200px | 80 | 90 | 80 | 通常の曲線 |

## 効果

- 近接ブロック間でS字カーブが発生しない
- 遠距離ブロック間の滑らかな曲線は維持
- 制御点が相手側に越境しないことを保証
