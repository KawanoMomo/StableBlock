# ECN-008: 注釈レイヤーのレイアウト安定化

- **ステータス**: 解決済
- **対象コミット**: `aa8fbb9`
- **影響ファイル**: `stableblock.html`, `vscode-stableblock/src/extension.js`

## コンテキスト

注釈（Annotation）レイヤーのUI要素が操作のたびにレイアウトシフトを起こし、ツールバーのボタンが意図しない位置に移動する問題があった。

## 問題の詳細

1. **Editボタンのレイアウトシフト**: `display:none` で非表示にしていたため、表示切替時にボタン配置がずれた
2. **モード混在**: 注釈編集モードでブロック/グループ追加ボタンが表示されており、誤操作の原因になった
3. **ノートテキスト入力**: 単行inputでは長い注釈テキストが入力しづらい
4. **ノートテキスト表示**: 中央揃えで読みづらい

## 対策

### レイアウト安定化

Editボタンの非表示方式を `display:none` から `opacity` 切替に変更。要素がDOMに残り続けるためレイアウトシフトが発生しない。

```
非アクティブ: opacity: 0.4（薄く見えるが場所は占有）
アクティブ:   opacity: 1.0
```

### モード別ツール表示

プロパティパネルの内容を `annotationEdit` フラグに応じて切替。

- **注釈編集モード**: ノート追加ボタンのみ表示
- **通常モード**: ブロック/グループ/接続追加ツールを表示

### テキスト入力・表示の改善

- 単行 `<input>` → `<textarea>` (高さ80px)に変更
- テキスト描画: `text-anchor="middle"` → `text-anchor="start"`（左上寄せ）
- フォント: `font-weight: 400`（標準）で可読性向上

## 結果

- ツールバーのレイアウトが安定し、ボタン位置が変動しない
- モードに応じた適切なツールのみ表示され、誤操作が防止される
- 注釈テキストの入力・閲覧性が向上
