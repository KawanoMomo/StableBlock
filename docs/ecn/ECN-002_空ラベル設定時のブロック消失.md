# ECN-002: 空ラベル設定時のブロック消失

- **ステータス**: 解決済
- **Issue**: #2
- **対象コミット**: `079781e`
- **影響ファイル**: `stableblock.html`, `vscode-stableblock/src/extension.js`

## コンテキスト

ブロックのラベルを空文字にするとブロックが消失（削除）される不具合が発生した。

## 問題の詳細

DSLパーサーの正規表現が `[^"]+`（1文字以上）で定義されていたため、空文字列 `""` がマッチせず、パース結果からブロック定義が脱落した。これにより空ラベルのブロックが描画されなくなった。

影響箇所:
- パーサー本体
- DSLアップデータ関数（`updatePos`, `updateSize`, `updateLabel`）

## 対策

正規表現の量指定子を `+`（1回以上）から `*`（0回以上）に変更した。

```
変更前: [^"]+  （1文字以上マッチ）
変更後: [^"]*  （0文字以上マッチ）
```

パーサーおよび全DSLアップデータ関数（`updatePos`, `updateSize`, `updateLabel`）に同一の修正を適用。

## 結果

- 空ラベル `""` がDSLとして有効になり、ブロックが正常に保持・描画される
- 既存の非空ラベルへの影響なし
