# ECN-006: 接続面選択アルゴリズムの改善

- **ステータス**: 解決済
- **対象コミット**: `2849f7d`
- **影響ファイル**: `stableblock.html`, `vscode-stableblock/src/extension.js`

## コンテキスト

2ブロック間の接続線がどの辺（上下左右）から発着するかの自動判定が、対角配置のブロックで誤った面を選択していた。

## 問題の詳細

旧アルゴリズムはブロック中心点間の角度（center-to-center angle）で接続面を決定していた。この方式ではブロックサイズが異なる場合や対角配置の場合に、視覚的に不自然な面が選ばれる。

例: `mobile` → `gw_main` で右下に配置されたブロックに対し、bottom→top ではなく left→right が選択される。

## 対策

角度ベースからエッジギャップベースのアルゴリズムに変更した。

### エッジギャップアルゴリズム

対向する辺間の空間距離（ギャップ）を計算し、最大ギャップの方向を接続面とする。

```javascript
gapB = toBlock.y - (fromBlock.y + fromBlock.h)  // from下辺 → to上辺
gapT = fromBlock.y - (toBlock.y + toBlock.h)      // from上辺 → to下辺
gapR = toBlock.x - (fromBlock.x + fromBlock.w)    // from右辺 → to左辺
gapL = fromBlock.x - (toBlock.x + toBlock.w)      // from左辺 → to右辺

vBest = max(gapB, gapT)
hBest = max(gapR, gapL)
→ vBest >= hBest なら縦方向、そうでなければ横方向
```

### 旧方式との違い

| 方式 | 判定基準 | 弱点 |
|------|---------|------|
| 角度ベース | 中心点間の角度 | ブロックサイズの差異を考慮しない |
| ギャップベース | 辺間の実距離 | なし（ブロック形状を正確に反映） |

## 結果

- 対角配置・サイズ差があるブロック間でも視覚的に自然な接続面が選択される
- ブロックの実際の辺位置に基づくため、直感に反する接続が解消
