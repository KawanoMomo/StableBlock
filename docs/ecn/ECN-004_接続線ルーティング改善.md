# ECN-004: 接続線ルーティングの改善

- **ステータス**: 解決済
- **Issue**: #5, #6
- **対象コミット**: `3260405`
- **影響ファイル**: `stableblock.html`, `vscode-stableblock/src/extension.js`

## コンテキスト

同一ブロックの同じ辺に複数の接続線が集中した場合、ポートが重なり接続先の判別が困難だった。また、矢印が斜めにブロックに入射するため方向性が不明瞭だった。

## 問題の詳細

1. **ポート重複**: 全接続線がブロック辺の中央1点から発着しており、複数接続時にパスが重なる
2. **矢印方向の不明確さ**: ベジェ曲線が中心点同士を結ぶ単純なパスで、ブロック辺に対して斜めに入射する

## 対策

### ポート分散アルゴリズム

新規関数 `computePorts()` を導入し、同一辺の接続ポートを均等分散させた。

- 各辺のポート数を集計
- 対向ブロックの位置に基づきポートをソート（線の交差を最小化）
- `portPos()` で辺に沿って均等間隔にポート座標を計算

### 直交スタブセグメント

新規関数 `stubPt()` を導入し、ブロック辺に垂直な短いスタブ線を追加した。

- パス構造: `スタブ線 → ベジェ曲線 → スタブ線`
- 矢印が常にブロック辺に対して直角に入射し、方向性が明確になる

## 結果

- 複数接続線が同一辺で重ならず、個別に識別可能
- 矢印の入射角が90度で統一され、接続方向が一目で判別可能
- ポートのソートにより線の交差が最小化
