# ECN-023: 少数接続時のポート間隔調整

- **ステータス**: 適用済
- **種別**: 改善
- **対象コミット**: `2310ed8`
- **影響ファイル**: `stableblock.html`, `vscode-stableblock/src/extension.js`

## コンテキスト

ECN-004で導入したポート分散アルゴリズムにより、接続線がブロック辺に沿って分散されるようになったが、接続数が少ない（2本）場合にもポートが辺の20%/80%位置に配置され、隣接ブロック間でも目立つ曲線が発生していた。

## 対策

ポート間隔のパディング値を接続数に応じて動的に調整する。

```javascript
// 変更前: 固定パディング
pad = 0.2  // 常に20%/80%

// 変更後: 接続数に応じた可変パディング
pad = total <= 2 ? 0.4 : total <= 4 ? 0.25 : 0.15
```

| 接続数 | pad | ポート位置 | 中心からのオフセット |
|--------|-----|-----------|-------------------|
| 1 | — | 50%（中央） | 0px |
| 2 | 0.4 | 40%/60% | 6px |
| 3-4 | 0.25 | 25%〜75% | 中程度 |
| 5+ | 0.15 | 15%〜85% | 最大 |

## 効果

- 隣接ブロック間の2本接続がほぼ直線で描画される
- 多数接続時は従来通り広く分散して重なりを防止
- 接続数に応じた自然な曲線度合い
