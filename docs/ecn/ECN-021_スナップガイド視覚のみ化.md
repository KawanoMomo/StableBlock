# ECN-021: スナップガイドの視覚のみ化

- **ステータス**: 適用済（後にECN-011で機能自体を無効化）
- **種別**: 改善
- **対象コミット**: `3d05483`
- **影響ファイル**: `stableblock.html`

## コンテキスト

スナップガイド機能がドラッグ位置を自動補正するため、ブロックが意図しない位置にジャンプし、1グリッド単位の精密な移動ができなかった。

## 対策

スナップガイドから位置強制（snap-to-grid）機能を除去し、ガイドラインの視覚表示のみを残す設計に変更。

### 削除した処理

- スナップ距離の閾値 (`snap=1`) による位置補正
- `bestV`/`bestH` 計算による `dx`/`dy` の修正
- 位置調整: `dx += (bestV.pos - px)`, `dy += (bestH.pos - py)`

### 残した処理

- 辺が正確に一致（`===`）する場合のガイドライン表示
- 4方向の整列チェック（左揃え、右揃え、右隣接、左隣接）
- 黄色破線によるガイドライン描画

## 設計判断

自動スナップは利便性と制御性のトレードオフがあり、グリッドベースの図作成ツールでは「正確に1グリッド移動」できることが優先されると判断した。ガイドラインは「現在揃っている」ことの確認用として残す。

## 後続

ECN-011にて性能問題によりスナップガイド機能自体が無効化された。
