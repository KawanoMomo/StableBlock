# ECN-014: バージョンバッジ正規表現の修正

- **ステータス**: 解決済
- **対象コミット**: `401dc50`
- **影響ファイル**: `bump-version.sh`

## コンテキスト

バージョンバンプスクリプトがHTMLファイル内のバージョンバッジを正しく更新できていなかった。

## 問題の詳細

`bump-version.sh` のsed正規表現が、バージョン番号の後に `スペース+英字テキスト` が続くパターンを想定していた。

```bash
# 旧パターン
s/v[0-9.]\+ [A-Za-z]*/
```

しかし実際のHTMLでは、バージョン番号の直後に `</span>` タグが続いており、スペース+英字のパターンに一致しなかった。結果、バッジ表示が `v0.5` のまま `v0.6` に更新されなかった。

## 対策

sed正規表現をHTML構造に合致するパターンに修正。

```bash
# 変更前: スペース+英字テキストを期待
s/v[0-9.]\+ [A-Za-z]*/

# 変更後: </span>閉じタグを期待
s/v[0-9.]\+<\/span>/
```

## 結果

- バージョンバンプ時にHTMLバッジのバージョン表示が正しく更新される
- `bump-version.sh` による一括バージョン管理が全ファイルで正常動作
