# [DRAFT] @include を作図 UI(ツール欄)から足す・外す

- ステータス: ドラフト(未採番。承認後 /adr で正式登録)
- 日付: 2026-09-26
- 起点: BLK-primary-20260926-1205-friction(6 枚それぞれの本文欄に `@include "shared/common.sb"` を手打ちしていた)

## コンテキスト
@include の入口が本文欄しか無かった。「.sb 読込」で選んだ図はブラウザがフォルダを渡さないので、
図のキーは名前だけ(`common.sb`)で、本文に書くべき `shared/common.sb` を画面側で知る手段が無い。

## 選択肢
1. ツール欄(何も選んでいないとき)に「共通部(@include)」: 今の @include 行(外す)、一緒に読み込んだ図の選択、本文に書くパスの欄、
   「この図に取り込む」「読み込んだ図すべてに取り込む」
2. ツールバーに「+ 共通部を取り込む」ボタンとダイアログ
3. フォルダごと読み込む(webkitdirectory)入口を足してパスを確定する

## 決定
案 1。文書全体の設定(キャンバスの寸法・自動で広げる)と同じ欄に置き、新しいボタン・タブを増やさない。
本文に書くパスは、同じフォルダのほかの図が既にその図を include している書き方を手本にし(`shared/common.sb`)、手本が無ければ相対パスを出して欄で直せる。
欄のパスが別の読み込んだ図を指していれば、選択欄よりパスを正とする。候補の並びは、ほかの図が取り込んでいる図 → 自分の接続が指していて自分に無い ID を
定義している図 → 残り(選ばずに押せば共通部が入る)。自分自身・取り込み済み・自分を取り込んでいる図は候補に出さない(循環を作らない)。
案 3 はブラウザの選択ダイアログが変わり、primary の「12 枚 + 共通部を選ぶ」操作と合わない。
判定は core/check(includeCandidates / addIncludeInDsl / removeIncludeInDsl)に置き unit で守る。

## 影響
- 足す位置は最後の @include 行の後、無ければ @canvas 行の後(差分 1 行)。「すべてに」で変わったほかの図は「.sb 保存」で書き出される
