# ECN-019: 接続線スタイル（実線/破線）

- **ステータス**: 適用済
- **種別**: 機能追加
- **対象コミット**: `cc7d62d`
- **影響ファイル**: `stableblock.html`

## コンテキスト

全ての接続線が同一の実線スタイルで描画されており、依存関係の種類（強い依存/弱い依存、同期/非同期等）を視覚的に区別できなかった。

## 対策

プロパティパネルに接続線スタイル切替ボタン（solid/dashed）を追加。接続選択時に表示され、`setConnProp()` でDSLのスタイル属性を更新する。

- `solid`: 実線（デフォルト）
- `dashed`: 破線（`stroke-dasharray` でSVG描画）

## 効果

- 接続の種類を線種で視覚的に区別可能
- DSL属性として保存されるため、エクスポート時も反映
