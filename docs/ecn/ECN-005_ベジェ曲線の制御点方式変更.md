# ECN-005: ベジェ曲線の制御点方式への変更

- **ステータス**: 解決済
- **対象コミット**: `08e5011`
- **影響ファイル**: `stableblock.html`, `vscode-stableblock/src/extension.js`

## コンテキスト

ECN-004で導入したスタブ線+ベジェ曲線の3セグメント構造で、スタブ線とベジェ曲線の接続部に角度の不連続（折れ）が発生していた。

## 問題の詳細

`M → L（スタブ線）→ C（ベジェ）→ L（スタブ線）` のパスは直交スタブと曲線の接点で接線方向が一致せず、鋭角な折れが生じる。視覚的に滑らかさに欠け、複雑な図で見づらくなる問題があった。

## 対策

3セグメント構造を廃止し、単一の3次ベジェ曲線（Cubic Bezier）に変更した。制御点をブロック辺の法線方向に配置することで、曲線がブロック辺に対して自然に垂直に到達する。

```
変更前: M(始点) L(スタブ端) C(ベジェ) L(終点)  ← 3セグメント
変更後: M(始点) C(cp1, cp2, 終点)               ← 単一ベジェ
```

制御点の距離は `max(30, 端点間距離 × 0.4)` で動的に計算。

- `stubPt()` を `extPt()` にリネーム（制御点計算用に転用）
- `bpath()` を単一 `M...C...` パスに簡素化

## 結果

- 接続線が完全に滑らかな曲線で描画される
- ブロック辺への直交入射は制御点の法線配置により自然に実現
- SVGパス要素が1つに削減され、レンダリング負荷が軽減
