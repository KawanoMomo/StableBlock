# ECN-007: VSCode プレビューの正規表現エラー

- **ステータス**: 解決済
- **Issue**: #7
- **対象コミット**: `ff75b33`
- **影響ファイル**: `vscode-stableblock/src/extension.js`

## コンテキスト

VSCode拡張のプレビューパネルが完全に表示されなくなる致命的な不具合が発生した。

## 問題の詳細

ID自動修正機能 `fixN()` の正規表現で、テンプレートリテラル内の文字クラス `[.*+?^${}()|[\\]\\\\]` にエスケープされていない `${}` が含まれていた。JavaScriptのテンプレートリテラルがこれをテンプレート補間として解釈し、不正な正規表現（未終了の文字クラス）が生成された。

この `SyntaxError` によりWebview内のスクリプト全体のロードが失敗し、プレビューが白画面になった。

## 対策

正規表現のメタ文字エスケープ処理を削除し、単純な単語境界マッチに簡素化した。

```javascript
// 変更前: メタ文字エスケープ（テンプレートリテラルと干渉）
new RegExp('\\b' + r.o.replace(/[.*+?^${}()|[\\]\\\\]/g, '\\$&') + '\\b', 'g')

// 変更後: 単純な単語境界マッチ
new RegExp('\\b' + r.o + '\\b', 'g')
```

`__new_N` 形式のIDは英数字とアンダースコアのみで構成されるため、正規表現メタ文字のエスケープは不要。

## 結果

- プレビューパネルが正常にロードされるようになった
- ID自動修正機能が正常に動作
- 不要なメタ文字エスケープ処理の除去によりコードが簡素化
