# ECN-026: エディタ機能8項目の一括追加

- **ステータス**: 適用済
- **種別**: 機能追加
- **対象コミット**: `6355ee1`
- **影響ファイル**: `stableblock.html`, `vscode-stableblock/src/extension.js`

## コンテキスト

エディタとしての機能性を一括で拡張した。v0.6.0リリースに向けた機能充実。

## 追加機能一覧

### 1. 接続線の太さ（`width=N`）

DSL属性に `width=N` を追加。UI上に太さ選択ボタン（1, 1.5, 2, 3, 4）を表示。デフォルト1.5。重要な接続を太線で強調可能。

### 2. 複数選択→グループ化

選択中の複数ブロックからバウンディングボックスを計算し、1クリックでグループを作成する `groupSelected()` 機能。

### 3. エクスポート拡張

- 透過背景PNG (`exportPNGTransparent()`)
- クリップボードコピー (`copyPNG()`)

### 4. 検索/フィルタ

ツールバーに検索入力欄を追加。マッチしない要素を `opacity: 0.2` でディミング。`doSearch()` と `matchesSearch()` で名前・ラベルをフィルタリング。

### 5. スナップガイド

ドラッグ中に1グリッド閾値で整列ガイドライン（黄色破線）を表示。（後にECN-021で視覚のみ化、ECN-011で無効化）

### 6. Mermaidエクスポート

`exportMermaid()` で図をMermaid flowchart TD形式に変換。グループはsubgraphに対応。

### 7. @includeディレクティブ

パーサーが `@include` を認識し、外部ファイルの取り込みをサポート。`preprocessInclude()` でfetch/extension経由の前処理。キャッシュ機構付き。

### 8. Git Visual Diff（VSCode）

VSCode拡張にHEADとの差分をサイドバイサイドSVGで表示するコマンドを追加。

## 設計判断

多数の小機能を1コミットにまとめた理由は、各機能が独立しており個別のコミットに分割する粒度に達しないため。ADRとしても1文書にまとめる。

## 効果

- エディタとしての総合的な機能性が大幅に向上
- Mermaidエクスポートにより他ツールとの連携が可能
- 検索機能により大規模図でのナビゲーションが容易
