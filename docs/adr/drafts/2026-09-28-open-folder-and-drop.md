# [DRAFT] 「.sb 読込」を ▾ にしてフォルダ単位で読めるようにする(ドロップも同じ)

- ステータス: ドラフト(未採番。承認後 /adr で正式登録)
- 日付: 2026-09-28
- 起点: BLK-junior-20260926-1705-wish(担当の図と共通部を毎回 1 枚ずつ選び直している。「プロジェクト」として覚えたい)

## コンテキスト
「.sb 読込」はファイル選択(複数可)だけで、本体と include 先を毎回選び直していた。owner の統合案は「プロジェクト」という保存物や画面を作らず、
選ぶ単位をフォルダに広げること(組の記憶はフォルダと本文の @include が持つ。VSCode のフォルダを開く・Obsidian の vault と同じ)。

## 選択肢
1. 「.sb 読込」はそのまま(1 クリックでファイル選択)にし、PNG と同じ分割ボタンの ▾ に「フォルダを選ぶ」を置く
2. 「.sb 読込 ▾」1 つにし、開くと「ファイルを選ぶ」「フォルダを選ぶ」を並べる
3. 「フォルダを開く」ボタンを別に足す

## 決定
案 2。BLK の指定どおりで、原則「1 つの機能に入口は 1 つ」「入口を足すときは同じ目的のボタンを ▾ に畳む」に合う。案 1 はツールバーのボタン(▾)が 1 つ増え、
案 3 は同じことをする入口が 2 つになる。ファイル選択は 1 クリック増えて 2 クリックになる(開いたメニューは先頭にフォーカスがあり、Enter でも選べる)。

- フォルダを選ぶと配下の .sb / .stableblock を全部読む(.txt・.xlsx 等と、.git などの隠しフォルダの下は読まない)。パスの順に並べ、ほかの図から
  include されていない最初の図を本文に出す(今までの本体の決め方を core/check の `pickMainDiagram` に移した)
- 選んだフォルダの名前は図のパスから外す(`trimCommonDir`)。画面の図名・「取り込む」のパス・一括書き出しの zip の中の名前は「shared/common.sb」のようにフォルダの中のパスになる。
  ファイル選択で読んだ図はこれまでどおり名前だけ(フォルダが分からない)
- プレビューへファイル・フォルダを落としても同じに読む(draw.io・VSCode と同じ)。フォルダは `webkitGetAsEntry` で辿り、取れないブラウザは落としたファイルだけを読む。
  ドラッグ中はプレビューに「ここに離すと読み込む」を出す
- 「一括 ▾」は前回選んだ形式を「前回」の印付きで先頭に出す(開くとそこにフォーカス)。利用者ごとの表示の便宜なので localStorage に持ち(読めなければ元の並び)、本文には書かない

## 影響
- 「.sb 読込」を押してすぐファイル選択が出ていた人は、メニューで「ファイルを選ぶ」を 1 回多く押す。scenarios の `importSb` もこの 2 クリックで開く
- include 先が読めないときの案内は「(「.sb 読込 ▾」でフォルダを選ぶか、本体と一緒に選ぶ)」
- VSCode 拡張はフォルダを開くのが元からの形なので変えない
