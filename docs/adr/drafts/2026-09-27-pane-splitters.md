# [DRAFT] 欄の境界はドラッグで幅を変え、幅は図でなく画面(このブラウザ / Webview)に覚える

- ステータス: ドラフト(未採番。承認後 /adr で正式登録)
- 日付: 2026-09-27
- 起点: BLK-human-20260926-2105-1(v1.0 所感: DSL・PREVIEW・ツールの境界をドラッグで変更できない)

## コンテキスト
HTML 版は DSL 欄(30%)・プレビュー(残り)・ツール欄(220px 固定)の 3 列で、境界を動かす手段が無かった(リポジトリの履歴にも無い)。
長い行の DSL を読むとき、プロパティ欄の長い名前を見るときに幅を変えたい。VSCode 拡張は DSL が VSCode のエディタで、
Webview の中はプレビュー | サイド欄の 2 列。

## 選択肢
1. 幅を `@canvas` 行など図の本文に書く — 図の性質ではなく見る人の画面の都合。Git 差分に意味の無い行が出る
2. 幅を覚えない(開き直すと既定に戻る) — 毎回ドラッグし直しになる
3. 幅はこのブラウザ(localStorage)/ Webview の state に覚え、ダブルクリックで既定に戻す

## 決定
案 3。幅の決め方(最小幅・プレビューに最小幅を残す・入り切らないときどちらを削るか)は `core/layout` の純粋関数 `paneWidths` に置き、
HTML 版と拡張の両方が使う。境界のつかみ(6px)は欄の幅を食わず、スクロールバーの無い側の余白に重ねる(左の境界はプレビューの左の余白、
右の境界はツール欄の左の余白)。←/→ キーでも 16px ずつ動く(キャンバスの矢印キー移動には渡さない)。

## 影響
- principles「GUI はテキストに無い状態を持たない」の対象は図の状態で、欄の幅は画面の状態なので外れない
- プレビューの左端 5px はクリックすると境界をつかむ(余白クリックで選択を外すのはその右から)
