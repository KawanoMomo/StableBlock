# ECN-015: ドラッグ/リサイズ性能最適化

- **ステータス**: 適用済
- **種別**: 性能改善
- **対象コミット**: `2fb8772`
- **影響ファイル**: `stableblock.html`, `vscode-stableblock/src/extension.js`

## コンテキスト

複雑な図（多数のブロック・接続線）でのドラッグ・リサイズ操作が重く、フレーム落ちが発生していた。

## 対策

### 1. requestAnimationFrame バッチング

mousemoveイベントごとに即座にレンダリングするのではなく、`requestAnimationFrame` (RAF) でフレーム単位にバッチ化。複数のmousemoveイベントが1回の描画フレームに統合される。

- ドラッグ中: `dragRaf` にRAF IDを保持、mouseupで `cancelAnimationFrame()` 後に最終refresh
- リサイズ中: `resizeRaf` にRAF IDを保持、同様にmouseupで最終処理
- `syncEditor()` はドラッグ中は呼び出さず、mouseup時に1回のみ実行

### 2. computePorts findIndex の排除

接続ポート計算で毎回 `findIndex()` (O(n)) を使用していた箇所を、ソート後にインデックスマップ `idxMap` を事前構築するO(1)ルックアップに変更。

```javascript
// 変更前: 毎接続でO(n)探索
const idx = group.findIndex(c => c.id === conn.id);

// 変更後: O(1)ルックアップ
const idxMap = {};
group.forEach((c, i) => idxMap[c.id] = i);
const idx = idxMap[conn.id];
```

## 効果

- ドラッグ操作の描画負荷が60-70%削減（見積もり）
- 大規模図でのフレームレートが安定
