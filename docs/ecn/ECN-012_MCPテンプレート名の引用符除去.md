# ECN-012: MCP テンプレート名の引用符除去

- **ステータス**: 解決済
- **対象コミット**: `cb60d6f`
- **影響ファイル**: `mcp-server/src/stableblock_mcp/tools/smart.py`

## コンテキスト

MCP（Model Context Protocol）サーバーの `sb_from_template` ツールでテンプレート名の検索が失敗する不具合が発生した。

## 問題の詳細

MCP Inspectorなどのクライアントがパラメータ値をクォート付きで送信する場合がある（例: `"basic"` → `'"basic"'`）。テンプレート名の辞書検索時にクォートが含まれたままの文字列で検索するため、キーが一致せずテンプレートが見つからなかった。

## 対策

テンプレート名のルックアップ前に、前後の空白とクォートをストリップする1行を追加。

```python
template = template.strip().strip('"').strip("'")
```

処理順序:
1. 前後の空白を除去
2. ダブルクォートを除去
3. シングルクォートを除去

## 結果

- クォート付き/なしどちらのパラメータでもテンプレート検索が正常動作
- MCP Inspector経由でのツール実行が安定
