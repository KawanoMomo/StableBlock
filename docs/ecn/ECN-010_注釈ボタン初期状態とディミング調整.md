# ECN-010: 注釈ボタン初期状態とディミング調整

- **ステータス**: 解決済
- **対象コミット**: `9ff502d`
- **影響ファイル**: `stableblock.html`, `vscode-stableblock/src/extension.js`

## コンテキスト

注釈レイヤーに関する初期表示状態とディミング（透過）表示の問題があった。

## 問題の詳細

1. **初期状態の不整合**: `showAnnotations` のデフォルト値が `true` で、注釈ボタンが初期ロード時にハイライト状態で表示されていた。実際には注釈データが空の状態であり、ユーザーに誤解を与えた。
2. **ディミング強度の問題**: 注釈編集モードのブロック/グループ/接続のディミングがハイライトモードと同じ `opacity: 0.15` で、ブロックがほぼ見えなくなり位置関係の把握が困難だった。

## 対策

### 初期状態の修正

```javascript
// 変更前
showAnnotations = true  // + ボタンにtb-anno-activeクラス付与

// 変更後
showAnnotations = false // ボタンは非ハイライト状態で表示
```

### ディミングの分離

用途別に2つのopacity値を定義し、ハイライトモードと注釈編集モードのディミングを分離した。

| モード | 変数 | opacity値 | 目的 |
|--------|------|-----------|------|
| ハイライトモード | `dim` | 0.15 | 非接続ブロックを強く抑制して接続関係を強調 |
| 注釈編集モード | `annoDim` | 0.35 | ブロックを薄くしつつ位置関係は把握可能に |

ブロック、グループ、接続線の描画処理で、現在のモードに応じた適切なopacity値を適用するよう分岐を追加。

## 結果

- 初期ロード時の表示が実際の状態と一致
- 注釈編集中もブロック配置を確認しながら注釈を配置できる
- ハイライトモードの強いディミングは維持
