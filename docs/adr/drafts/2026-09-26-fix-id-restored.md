# [DRAFT] ツールバーの「ID補正」を戻し、仮の ID の一括付与の入口にする。自動拡張の知らせはプレビューの上端に出す

- 改める判断: `2026-09-25-id-in-property-panel.md`(「ID補正」を畳んだ)。`2026-09-26-canvas-grow-off.md` の「広げた直後はステータスバーに出す」

## コンテキスト
ID をプロパティ欄で決められるようにしたとき、ツールバーの「ID補正」を畳んだ。新しい要素はラベルを打てば ID が付くが、
貼り付けた要素・本文でラベルを直した要素・英数字の無いラベルの要素は `__new_N` のまま残る。人間はもともと
「ラベルだけ書けば ID は一括で補正される」形を望んでいた(BLK-human-20260926-1010-2)。
キャンバスの自動拡張は `grow=off` と「元の寸法に戻して固定」を足したが、知らせは下端のステータスバー(10px)にしか出ず、人間は変化に気付かなかった。

## 決定
- 「ID補正」をツールバーに戻す(拡張は「Fix IDs」)。対象は仮の ID(`__new_`)の要素だけ。ラベルの表記のまま ID を付け(重なれば `_2`)、
  接続の from / to も追従する(core/label の `fixPlaceholderIdsInDsl`。HTML 版・拡張が共用)。include 先の要素には触れない。
  旧版の Shift+クリック(全 ID の付け直し)は戻さない: ほかの図が参照する ID を黙って変えるため。既存の ID の改名はプロパティ欄の ID 欄(図をまたいで追従)
- 付けた ID と、英数字の無いラベルで付けられなかった要素は右下の知らせに出す(押すと閉じる)
- 1 つずつの改名(ID 欄)と一括の付与(ID補正)は別の機能なので、入口が 2 つになるわけではない
- 自動で広げた知らせは、プレビューの上端の帯に「キャンバスを広げた A → B [元の寸法に戻して固定] [このまま]」で出す(操作は止めない)。
  以後も広げるかは下端の「Canvas: 幅×高さ 自動拡張 / 固定」から切り替える(BLK-human-20260926-2045-3)
